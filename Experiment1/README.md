# G.L. Bajaj Online Book Store

A front-end web development project created as part of a college lab. The site presents a simple online bookstore for browsing academic books and exploring department-specific reading lists.

## Features

- Book catalogue with titles, authors, prices, and online cover images
- Cart page with a sample order summary
- Login and registration form pages
- Department pages for CSE, ECE, Electrical, and Mechanical
- Responsive styling with a consistent color theme

## Built With

- HTML5
- CSS3

## Run Locally

Open `index.html` in a web browser. No installation or build step is required.

> This is a front-end demonstration. Login, registration, and checkout are not connected to a backend.
